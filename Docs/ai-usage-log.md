# AI Usage Log

> **The canonical, up-to-date AI usage log lives at the repository root:
> [`../AI_USAGE_LOG.md`](../AI_USAGE_LOG.md).**
>
> It is kept in one place to avoid two logs drifting apart. Add new entries
> there, not here.

Every AI-assisted contribution must be logged honestly with: date, tool,
purpose, what output was used, who reviewed it, and what was changed. Use this
table shape (mirrors the root log):

| Date | Tool | Purpose | Output Used | Reviewed By | Changes Made |
|------|------|---------|-------------|-------------|--------------|
| YYYY-MM-DD | (tool) | (what you asked for) | (what was kept) | (tests/build/review) | (what changed) |

See the root log for the full history.
